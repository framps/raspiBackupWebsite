I take the protection of your data seriously. This website is a private, non-commercial project. It uses no analytics or tracking services, no advertising and no marketing cookies. The following explains which data is processed when you visit this website.

1. Controller

The controller for data processing on this website within the meaning of the General Data Protection Regulation (GDPR) is the person named in the imprint.

2. Hosting and server log files

This website is hosted in Germany by: Hetzner Online GmbH, Industriestr. 25, 91710 Gunzenhausen, Germany. A data processing agreement according to Art. 28 GDPR is in place with the provider.

Each time a page is requested, the web server automatically stores information transmitted by your browser:

  • IP address, which the hoster anonymises before storing it (the last part is replaced with a random value), so that it can no longer be attributed to a person
  • date and time of the request
  • requested page or file
  • referrer URL (the previously visited page)
  • browser and operating system
  • HTTP status code and amount of data transferred

This data is needed to deliver the website and to ensure its security and stability, for example to detect attacks. The legal basis is Art. 6 (1) (f) GDPR (legitimate interest). Because the IP addresses are only stored in anonymised form, I keep the log files permanently and evaluate them statistically to learn how the website and raspiBackup are used. The legal basis for this is also Art. 6 (1) (f) GDPR. The data is not combined with other data sources.

3. Cookies

This website sets only one technically necessary cookie:

  • pll_language: stores the selected language (German or English) so that you see the right language version on your next visit. Storage period: 1 year. It contains no personal data.

The legal basis is § 25 (2) No. 2 TDDDG (German Telecommunications Digital Services Data Protection Act), as the cookie is strictly necessary for the language selection you requested, and Art. 6 (1) (f) GDPR. No consent is required. When logging in to the administration area, WordPress sets further cookies; these only concern the operator of the website.

4. Fonts and external content

This website does not load any fonts, scripts or images from third-party servers. It uses the system fonts available on your device; Google Fonts are not used.

The number of GitHub stars and the current version number of raspiBackup are fetched from GitHub by the web server itself and cached. No visitor data is transmitted to GitHub.

5. YouTube videos

If a YouTube video is embedded on this website, it is loaded only after you click the play area. Before that, no connection to YouTube is made. After the click, the video is loaded in privacy-enhanced mode from youtube-nocookie.com. Among other things, your IP address and information about your browser are transmitted to Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Ireland; a transfer to the USA is possible. Google is certified under the EU-US Data Privacy Framework. The legal basis is your consent by clicking (Art. 6 (1) (a) GDPR, § 25 (1) TDDDG). More information can be found in Google's privacy policy.

6. raspiBackup usage statistics

At every start, but at most once a day, the raspiBackup software checks whether a new version is available. During this check it reports some usage information to the server www.linux-tips-and-tricks.de. The following is transmitted:

  • raspiBackup version
  • backup type (dd, tar or rsync) and backup mode (normal or partition-oriented)
  • number of backups kept or the smart recycle settings
  • function performed (backup, restore or clone)
  • operating system (Raspberry Pi OS or Ubuntu)

No host names, file names, backup contents or configuration data are transmitted. Like any other page request, the request is stored in the server log files with an anonymised IP address (see section 2). The evaluation shows me which versions and functions are used and helps to focus development and testing accordingly. The legal basis is Art. 6 (1) (f) GDPR.

Objection: If you do not want this, switch the report off by setting DEFAULT_SEND_STATS=0 in the configuration file /usr/local/etc/raspiBackup.conf. More information is available in the raspiBackup documentation under “Statistics”.

Version check at GitHub: raspiBackup downloads the information about the current version from raw.githubusercontent.com. As with any request to an internet address, GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA, receives the IP address of the Raspberry Pi. GitHub is certified under the EU-US Data Privacy Framework. I have no influence on this processing; GitHub's privacy statement applies. The legal basis for the version check is Art. 6 (1) (f) GDPR: users should be informed about new versions and bug fixes.

7. Links to other websites

This website contains links to other services, for example to the raspiBackup documentation on GitHub Pages, to GitHub, YouTube, Facebook, Reddit and X. These are ordinary links: the other site is only requested when you click a link. From then on, the privacy policy of the respective provider applies. No data is transmitted to these providers before that.

8. Contact by email or phone

If you contact me by email or phone, I process the data you provide (for example name, email address, phone number and the content of your message) only to handle your legal matter. The legal basis is Art. 6 (1) (f) GDPR. The data is deleted as soon as the matter has been settled and no statutory retention obligations apply. Requests that do not concern legal matters are deleted immediately, as described in the imprint.
